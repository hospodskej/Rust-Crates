# Rust Crates

Small, focused crates for Rust web development, each in its own folder under `crates/`.
They are named after parts of living things and electronics.

| Crate | What it does |
|---|---|
| [thymus](crates/thymus) | Password authentication: Argon2id hashing, timing-safe sign-in, reset tokens bound to the current password, safe `return_to` paths |
