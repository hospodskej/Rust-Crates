# Rust Crates

Small, focused crates for Rust web development, each in its own folder under `crates/`.
They are named after parts of living things and electronics.

| Crate | What it does |
|---|---|
| [attenuator](crates/attenuator) | Shrinks photos in the browser before upload (Rust/WASM): at most 1600 px, re-encoded as WebP, swapped into the file input |
