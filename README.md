# Rust Crates

Small, focused crates for Rust web development, each in its own folder under `crates/`.
They are named after parts of living things and electronics.

| Crate | What it does |
|---|---|
| [cuticle](crates/cuticle) | Tower layer for Axum that adds strict security headers, with a per-request Content-Security-Policy nonce for inline scripts and Leptos |
